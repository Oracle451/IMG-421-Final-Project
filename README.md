# IMG-421-Final-Project: IRON TIDE
Iron Tide is a top-down 3D naval combat game. Players command a customizable fleet, progressing inwards through a circular map experiencing increasing difficulty closer to the center. This map is populated by enemy fleets, naval bases, patrols, and coastal defenses. By defeating enemy ships and harvesting resources, players upgrade their fleet to eventually siege a massive central stronghold and win the game.
